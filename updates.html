PUBG Ban Checker Updates

A clear record of improvements to the checker, Watchlist, account sync, and the rest of the site.

Latest release

Version 2.2

27 August 2026
01

Watchlist refresh

  • Refresh All now checks players one at a time to protect the PUBG API from request bursts.
  • The active player displays a scanning animation and visible queue progress.
  • Each completed card updates individually without flashing or rebuilding the full list.
02

Observed history

  • Signed-in Watchlists retain check counts, status observations, name changes, and temporary-ban periods.
  • Conflicting PUBG responses are verified over time instead of immediately overwriting a known ban.
  • Possible permanent-ban reversals are supported and clearly described.
  • The search that adds a player now counts as their first observation.
03

New player dossiers

  • Wide player strips were replaced with compact, responsive dossier cards.
  • Status rails, structured metadata, expandable history, and consistent action footers improve scanning.
  • The design retains the cyan, violet, gold, and dark command-centre palette.
04

Site-wide polish

  • Navigation, page edges, content widths, gutters, and section spacing now share one layout system.
  • Core pages line up consistently at desktop, tablet, and mobile widths.
  • Responsive navigation now forms a clean grid without horizontal overflow.
